## Publicar con GitHub Pages

1. Crear un repositorio público en GitHub.
2. Subir todo el contenido de esta carpeta a la rama `main`.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar la rama `main`, carpeta `/ (root)` y guardar.

## Usar un dominio propio después

Cuando se compre el dominio `.com`, agregarlo en **Settings → Pages → Custom domain**. GitHub indicará los registros DNS necesarios. No se necesita rehacer la página.

## Estructura

- `index.html`: contenido y estructura.
- `styles.css`: identidad visual y diseño adaptable.
- `script.js`: enlaces de WhatsApp, menú móvil y animaciones.
- `assets/images/`: imágenes del negocio y productos.

Los precios y la disponibilidad deben mantenerse actualizados con el menú del negocio.
