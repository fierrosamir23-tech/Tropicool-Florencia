## Publicación

El sitio es estático y funciona directamente en GitHub Pages. Para conectarlo a un dominio propio en el futuro, se configura el dominio en **Settings → Pages → Custom domain** y se actualizan las etiquetas `canonical`, `og:url`, `og:image`, `robots.txt` y `sitemap.xml`.
